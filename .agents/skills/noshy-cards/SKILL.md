# NoShy cards

The user will not mention widgets or generative UI.

When a `noshy-concierge` tool returns an HTML document (it starts with `<!DOCTYPE html>`):

1. Show that document as one inline widget. Copy it unchanged.
2. Add at most one short sentence. Do not list the same people or projects as markdown.
