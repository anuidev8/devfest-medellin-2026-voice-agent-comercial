# One-shot variants prompt

Use with `soul.md` + mood boards.

---

You are designing from the project brain in `soul.md`.

Use the curated mood boards as visual inspiration. Do not copy images. Extract shared taste into distinct concepts.

Generate **8 one-shot variants** for this product surface.

Each variant must include:

- A distinct visual concept and layout
- The core interaction model from soul (e.g. listen-first, one-screen stages)
- Real copy derived from soul (not filler)
- A clear CTA
- Responsive behavior notes

Vary metaphors and layouts aggressively. After generating variants, create a disposable gallery page where I can compare them and pin favorites.

Then recommend **one** locked direction with a short rationale tied to soul.md.
