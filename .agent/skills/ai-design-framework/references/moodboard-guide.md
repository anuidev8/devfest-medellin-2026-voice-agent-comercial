# Mood board guide (Phase 3)

The mood board turns the top N references into **one named direction** a builder can follow.

## Steps

1. **Find the shared taste.** For each selected pin, write what it contributes (color, layout, texture, type, motion idea). Look for 2–3 traits that appear in most of them.
2. **Name the direction** with a concrete image, not adjectives: "Tidal Calm", "Paper Blueprint Factory". Avoid "Modern Clean".
3. **Blend** — say how much each pin influences it: `"60% 03-soft-orb, 25% 01-sand-minimal, 15% 05-rings"`.
4. **Accent (optional)** — one secondary board, used only for a defined context ("status panels only").
5. **Merge palettes.** Start from the extracted palettes in `sources.json`. Pick 5–8 colors and give each a role: `bg`, `surface`, `text`, `muted`, `accent`, `accent-2`, `line`. Prefer colors that actually appear in the pins, adjusted for contrast.
6. **Type** — suggest a display + body pair (Google Fonts or system) that matches the pins' type voice.
7. **Texture & shape** — radius (sharp / soft / pill), borders vs shadows, grain, gradients, imagery style.
8. **Feel keywords** (5–8): the words a user would use. **Motion keywords** (3–5): slow, rhythmic, snappy, springy, weightless…
9. **Rejected looks** — what we deliberately don't do (from rejected pins and the brief's non-goals).

## Don't

- Average every pin into a beige middle.
- Introduce colors that appear in none of the pins without saying why.
- Describe layouts you will copy 1:1 from a pin.
