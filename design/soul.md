# Test Design Skill — Commercial Voice Agent UI

## Purpose
A high-converting, immersive design test page showcasing our next-generation commercial voice AI agent.

## Audience
- Commercial decision makers, tech leads, and contact center innovators
- Customers testing interactive conversational voice agents

## User Problems
- Voice agents often feel sterile, invisible, or disorienting without visual feedback.
- Complex contact center metrics and real-time voice controls feel disjointed.

## Emotional Outcome
Users should feel:
- In control and confident in voice AI capabilities
- Visually engaged with responsive, living audio/speech feedback
- Sophisticated yet effortless clarity

## Tone
- Futuristic, deep, professional, radiant

## Core Modes or Features
- Live interactive voice sphere/orb feedback with audio reactivity
- Clean commercial dashboard widgets (active calls, latency, sentiment, transcripts)
- High-contrast responsive layout

## UI Principles
- Bioluminescent depth: deep dark navy backgrounds with focused electric blue & cyan glow
- Immediate voice visual status: clear indicator of agent listening, thinking, and speaking
- Sharp typography with clean, metric-driven cards

## Tech Context
- Stack: Next.js + Tailwind CSS
- Environment: Web (Desktop & Mobile)

## Non-Goals
- Generic white-label flat SaaS templates
- Overcrowded unreadable charts
